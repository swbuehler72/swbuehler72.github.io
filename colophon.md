This site is built on Gihub Pages, which uses [Jekyll](https://jekyll-rb.com) as the rendering engine.

Typeface via CSS is **Computer Modern** in Roman and Typewriter faces, which is familiar to academics and users of an older persuasion as the standard typeface of [Donald Knuth](https://www-cs-faculty.stanford.edu/~knuth/)'s $\TeX{}$ and its derivatives. Using it allows those pieces rendered with $\LaTeX{}$ like mathematical expressions to better blend in visually with the rest of the text.
