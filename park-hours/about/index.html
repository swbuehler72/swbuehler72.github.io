How these calendars are made

The park hours calendar, its printable PDF and the updates page are an unofficial personal project by Steven Buehler. This page explains where the information comes from and the terms for using it.

How it works

  1. Each morning after 6:30 AM Eastern, Claude, Anthropic's AI assistant, runs as a scheduled task in the Claude app on my computer. It opens Walt Disney World's public Hours & Events Calendar in a web browser and reads the hours for every date Disney has posted. Disney posts about 60 days ahead.
  2. For each day it records park hours for Magic Kingdom, EPCOT, Disney's Hollywood Studios and Disney's Animal Kingdom, along with Early Entry, Extended Evening Hours and separately ticketed events such as parties and Disney After Hours.
  3. Claude hands that information to a script, which checks that it's complete. If anything looks wrong, such as missing dates or a missing park, it stops and changes nothing.
  4. The script builds the web calendar and the two-page PDF, then publishes them to this site through GitHub Pages.
  5. It compares each day's information with the day before. Changes to dates already on the calendar, and events appearing for the first time, are listed on the updates page. Newly posted dates aren't listed there.

Festivals

Disney's hours calendar doesn't always list EPCOT festivals. When it doesn't, I add the festival's dates by hand from Disney's own page for that festival, and they appear in the calendar notes while some of those dates are on the calendar.

What's added here

Everything else on the calendar comes straight from Disney. This site only adds the layout, short labels for events (for example "Christmas Party" or "After Hours"), holiday names such as Thanksgiving, and the notes that summarize when events run.

Built with Claude

Claude Code, Anthropic's AI coding tool, built these pages and the script with me, and Claude runs the daily update. The script's checks are what keep a bad update from going out: daily updates publish automatically, without me reviewing each one. I review changes to how the site works.

Limits

  • The calendar is only as current as its last update. Disney can change hours at any time, including after the morning update.
  • An update can be missed, for example when my computer is off, so the calendar may lag by a day or more. The date of the last check is shown at the bottom of the calendar and the PDF.
  • The PDF is a snapshot. A printed or downloaded copy doesn't update.
  • Only the four theme parks are covered. Water parks, Disney Springs, parades, fireworks, character meals, closures and refurbishments are not included.
  • All times are Eastern. Early Entry and Extended Evening Hours are only for eligible guests, as Disney defines them.
